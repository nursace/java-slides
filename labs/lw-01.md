## Instructions

- Write a **complete Java program** for each exercise (one class with a `main` method unless noted).
- You may hard-code test values in `main`, or read from the keyboard with `Scanner` if you have already seen it in class. If you hard-code, put the values in clearly named variables and change them to try different cases.
- Stay within **one class + `main`**. No extra classes, no OOP beyond that.
- Do **not** use arrays. Do **not** rely on String methods (`equals`, `length`, `charAt`, …) as the focus of a solution. `String` may appear only for printing or simple `main` boilerplate.
- Topics: variables and primitive types, `if` / `else`, `switch`, loops (`for`, `while`, `do-while`).
- Compile and run your programs. Match the sample output style where samples are given (spacing and line breaks matter).

**Skills you should practise**

- Declaring and updating primitive variables (`int`, `double`, `boolean`, `char`)
- Integer division vs floating division, and `%`
- Branching with `if` / `else if` / `else` and logical operators
- Classic `switch` with `break` (and intentional fall-through only when useful)
- Writing `for`, `while`, and `do-while` without infinite loops

## Coding exercises

### Exercise 1 — Unit converter

Write a class `UnitConverter` with a `main` method.

- Declare a `double` variable `celsius` (choose a test value, e.g. `22.0`).
- Compute Fahrenheit with the formula:  
  `fahrenheit = celsius * 9.0 / 5.0 + 32.0`
- Print both values on separate lines in this style:

```text
Celsius: 22.0
Fahrenheit: 71.6
```

Also print the integer part of `fahrenheit` using a cast to `int` on a third line, labelled `Fahrenheit (truncated):`.

### Exercise 2 — Even or odd reporter

Write a class `EvenOdd`.

- Declare an `int` named `n` (try several values: positive, negative, and zero).
- Using `%` and `if` / `else`, print exactly one of:
    - `even`
    - `odd`
- Then, in the same program, print whether `n` is positive, negative, or zero (second line), using a separate `if` / `else if` / `else` chain.

**Sample** (when `n` is `7`):

```text
odd
positive
```

**Sample** (when `n` is `-4`):

```text
even
negative
```

### Exercise 3 — Grade from a score

Write a class `GradeLetter`.

- Declare an `int score` in the range you care about for testing (0–100).
- Print a single letter grade using `if` / `else if` / `else`:
    - 90–100 → `A`
    - 80–89 → `B`
    - 70–79 → `C`
    - 60–69 → `D`
    - below 60 → `F`
- If `score` is outside 0–100, print `Invalid score` instead of a letter.

**Sample** (`score = 83`):

```text
B
```

**Sample** (`score = 105`):

```text
Invalid score
```

### Exercise 4 — Ticket price calculator

Write a class `TicketPrice`.

- Declare `int age` and `boolean isStudent`.
- Base price is `12.0` (`double`).
- Apply **exactly one** discount rule, checked in this order:
    1. If `age < 12` → pay `5.0`
    2. Else if `age >= 65` → pay `7.0`
    3. Else if `isStudent` → pay `9.0`
    4. Else → pay the base price `12.0`
- Print the final price on one line, e.g. `Price: 9.0`

Test at least: child, senior, adult student, adult non-student.

### Exercise 5 — Day of week with `switch`

Write a class `DayName`.

- Declare an `int day` where `1` means Monday … `7` means Sunday.
- Use a **classic** `switch` (with `break` on each case) to print the day name.
- Use `default` to print `Invalid day` for any other value.

**Sample** (`day = 3`):

```text

```

**Sample** (`day = 0`):

```text
Invalid day
```

Optional extension in the same `main`: after the first switch, add a second switch that prints `weekday` for 1–5 and `weekend` for 6–7 (you may use fall-through deliberately for 1–5 and for 6–7).

### Exercise 9 — Digit counter (loops + conditionals)

### Exercise 10 — Menu with `do-while`

Write a class `SimpleMenu`.

Simulate a tiny text menu that always shows at least once. You may hard-code a sequence of choices in variables, **or** use `Scanner` if allowed.

**Behaviour**

1. Print:

   ```text
   1) Show greeting
   2) Show a number squared
   3) Quit
   ```

2. Read / select an `int choice`.
3. Use `switch` on `choice`:
    - `1` → print `Hello, Java student!`
    - `2` → declare an `int x` (hard-coded or read), print `x * x`
    - `3` → print `Goodbye` and stop the menu loop
    - anything else → print `Unknown option`
4. Wrap the menu in a `do-while` so it repeats until the user chooses `3`.

If you hard-code without `Scanner`, drive the loop with a small set of `choice` values you assign inside the loop (document your test sequence in comments). Prefer `Scanner` if your course has introduced it.

## Self-check hints (not full solutions)

- **Ex 1:** Use `9.0` and `5.0` (or cast) so the division is not integer division.
- **Ex 2:** `n % 2 == 0` means even; zero is even and neither positive nor negative.
- **Ex 3:** Check the invalid range **first**, then the letter bands from high to low (or carefully with inclusive bounds).
- **Ex 4:** Order matters: a 10-year-old student should get the child price, not the student price.
- **Ex 5:** Forget `break` and you fall through into the next `case`.
- **Ex 6:** `for (int i = 1; i <= 10; i++)` is a natural fit; print a space between values (trailing space is fine unless your lecturer forbids it).
- **Ex 7:** The `while` version must update the counter every iteration or it never ends.
- **Ex 8:** Integer overflow is unlikely for small classroom `n`; still prefer `long` only if your lecturer asks.
- **Ex 9:** Loop while the remaining value is greater than `0`, counting each `/ 10` step; handle `0` before the loop.
- **Ex 10:** `do-while` checks the condition **after** the body, so the menu appears at least once; quit when `choice == 3`.
